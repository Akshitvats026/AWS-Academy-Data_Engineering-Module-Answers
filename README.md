## ❓ Q1. Rule-Based Customer Analysis

**Question**  
A data scientist writes a program that applies rule-based logic to customer profile data to determine which customers are likely to respond to an advertisement. How would you categorize this type of analysis?

**Options**
- Machine Learning (ML)  
- Artificial Intelligence (AI)  
- Traditional Analytics  
- Preventive Analytics  

**Answer**  
✅ **Traditional Analytics**

**Reason**  
Traditional analytics relies on predefined programming logic and rules to generate predictions from data.

---

## ❓ Q2. Designing an Effective Decision-Making Infrastructure

**Question**  
Which statement describes a key factor in designing an effective decision-making infrastructure?

**Options**
- Focus on collecting data for all analytics  
- Prevent data transformation  
- Start with the business problem and build the pipeline accordingly  
- Use a fixed pipeline pattern for all use cases  

**Answer**  
✅ **Start with the business problem to be solved and then build the pipeline that suits that use case**

**Reason**  
The most effective infrastructures are designed around **business objectives**, not tools or data volume.

---

## ❓ Q3. Image-Based Car Identification

**Question**  
A customer wants to train a model using labeled images of cars so it can identify unlabeled images as cars. Which approach should be used?

**Options**
- Traditional Analytics  
- Natural Language Processing  
- Historical Analysis  
- Artificial Intelligence and Machine Learning (AI/ML)  

**Answer**  
✅ **Artificial Intelligence and Machine Learning (AI/ML)**

**Reason**  
AI/ML learns patterns from examples and works well with **unstructured data** like images.

## ❓ Q4. Using Data for Decision-Making

**Question**  
Which statement best reflects how organizations should think about using data?

**Options**
- Always store as much data as possible  
- Never sacrifice accuracy for speed  
- Data becomes more valuable over time  
- Preventive and predictive analytics provide the most value  

**Answer**  
✅ **Preventive and predictive analytics promise the most value**

**Reason**  
Predicting outcomes and acting before they occur delivers the highest business value.

## ❓ Q5. Role of a Data Scientist

**Question**  
Which statement best describes the role of a data scientist in a data pipeline?

**Options**
- Focus on infrastructure  
- Move data into the pipeline  
- Grant access permissions  
- Work with data in the pipeline  

**Answer**  
✅ **A data scientist works with data in the pipeline**

**Reason**  
Data scientists analyze and experiment with data to extract insights and support decisions.

---

## ❓ Q6. Nature of Data Processing

**Question**  
Which statement describes how data is processed through a pipeline?

**Options**
- Processing is rarely iterative  
- Only ingestion is iterative  
- Processing is almost always iterative  
- New data sources are unlikely after ingestion  

**Answer**  
✅ **Processing will almost always be iterative**

**Reason**  
Data analysis involves repeated hypothesis testing, experimentation, and refinement.

---

## ❓ Q7. Data Transformation in Pipelines (Select TWO)

**Options**
- Data might need to be cleaned or normalized  
- Data is transformed only once during ingestion  
- All ingested data is enriched  
- Data is transformed using ETL processes  
- ETL is not used in analytics  

**Answers**
✅ Data might need to be cleaned or normalized  
✅ Data will probably be transformed through ETL processes

## ❓ Q8. Role of a Data Engineer

**Question**  
What is the primary responsibility of a data engineer?

**Options**
- Train analysts  
- Build infrastructure  
- Evaluate results  
- Discover insights  

**Answer**  
✅ **Build the infrastructure that data passes through**

**Reason**  
Data engineers focus on reliability, scalability, and performance of data pipelines.

## ❓ Q9. AI/ML Innovation Strategy

**Question**  
Which strategy is recommended for innovating with AI/ML?

**Options**
- Focus only on structured data  
- Use cloud services that democratize AI/ML  
- Restrict ML to experts  
- Replace SQL completely  

**Answer**  
✅ **Take advantage of cloud services with AI/ML features that democratize access**

**Reason**  
Cloud platforms reduce complexity and enable broader adoption of AI/ML.

## ❓ Q10. “Unify” in Modern Data Infrastructure

**Question**  
What does the "unify" principle emphasize?

**Options**
- Using AI/ML for faster insights  
- Centralized access control  
- Migrating to purpose-built tools  
- Breaking down silos and democratizing access  

**Answer**  
✅ **Break down silos and democratize access**

**Reason**  
Unification creates a **single source of truth** accessible to multiple teams.
